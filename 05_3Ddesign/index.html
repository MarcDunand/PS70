<div class="textcontainer"> <p class="margin"> </p> <h3>Week 5: 3D Design & Printing</h3> <h4>Assignment: Model and 3D print something</h4> <div class="spacer"></div> <img style = "width: 550px" src = "./semiZoomed.png"> <p>For this week, I designed a casing to hold my four peristaltic pumps that I built and programmed a few weeks ago. This shape at first looks like it might have been made using subtractive methods, but there is one section that would have been very challening to achieve with something like a CNC.</p> <img style = "height: 200px" src = "./wiringHoles.png"> <img style = "height: 200px" src = "./wiringHolesCloseup.png"> <p>That's these small holes orthoganol to the large holes which slot into the pumps. These small holes are even with the bottom of the large holes and are there in order to allow the two wires that control each of the pumps to have a dedicated outlet from the frame.</p> <p>Other than that, I want to show off that I parameterized every measure for the casing:</p> <img style = "width: 700px" src = "./params.png"> <p>And that I used a rectangular pattern to arbitrarily control the number of pumps the casing is built for. (I am eventually planning on having eight pumps instead of four so this will be pretty useful.)</p> <img style = "width: 700px" src = "rectangPattern.png"> <p>This was a pretty simple print and actually required no additional supports at all, so I ran into no issues there and was able to get slide the pumps in and dig screws into the thinner holes along the top of the casing without worries!</p> <img style = "height: 350px", src = "finalBack.jpg"> <img style = "height: 350px", src = "./finalSide.jpg"> <div class="spacer"></div> <p>For the photogrammatry part of this assignment, I used the lab's tapping machine.</p> <img style = "height: 450px", src = "./tappingMach.jpg"> <p>This actually worked shockingly well on the very first attempt!
